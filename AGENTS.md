# Repository instructions

## Warehouse Shift

Read the [Warehouse Shift README](tools/warehouse-shift/README.md) before making changes to the game, its tests, or the multiplayer relay. It describes the gameplay, source files, progression, and testing setup.

Update that README in the same change whenever behaviour, controls, prices, saves, setup, deployment, or test instructions change. Keep affected in-game help accurate and update the [relay README](workers/warehouse-relay/README.md) for relay-specific changes. See the [coding agent instructions](tools/warehouse-shift/README.md#instructions-for-coding-agents) for the full handover checklist.
