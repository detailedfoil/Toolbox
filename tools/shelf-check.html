          GitHub token

          The two update area buttons need a GitHub token on this phone, once. It stays on this phone only.

          1. Make a new fine-grained token on GitHub.
          2. Repository access: Only select repositories, then Toolbox.
          3. Permissions: Contents and Actions, both set to Read and write.
          4. Generate it, copy it, paste it below.

          Device search (update area) saves its results for every store. GitHub search starts the full check on GitHub. A token made before 13 Oct may only have Contents: if GitHub search says it needs Actions too, edit the token on GitHub to add Actions: Read and write.
